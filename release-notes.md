**Скачать:** `RPp-Setup.exe` — установщик, `RPp-portable.zip` — версия без установки.

Что нового в 1.7.0:
- Звуковые дорожки в обрезке. Под панелью «Обрезка» звук показан волной: видно, где речь, а где тишина. На длинных записях волна приближается к выбранному фрагменту, и его края можно двигать прямо по ней.
- Несколько дорожек OBS (игра, микрофон, голосовой чат). Кнопкой с динамиком выберите, какие дорожки попадут в сохранённую копию; наушниками — какую слушать. Дорожку для прослушивания можно сменить и в меню «⋯».
- «Свести в одну»: выбранные дорожки смешиваются в одну, и запись со всем звуком открывается в Telegram, Discord и браузере, которые играют только первую дорожку. Картинка при этом не перекодируется.
- Вырезать кусок звука. Кнопка с ластиком на дорожке: протяните по волне участок, и в сохранённой копии на этом месте будет тишина (например, убрать фразу из микрофона, не трогая звук игры). То же самое — если тянуть с зажатым Shift. Правый щелчок по вырезанному куску возвращает звук. При просмотре вырезанное место тоже молчит.
- «Только звук»: третий вариант рядом с «Быстро» и «Точно» сохраняет звук фрагмента без картинки, в файл .m4a.
- Новый экран «Все папки». RPp сам показывает папки, в которых лежат видео: карточки с обложкой, числом записей и размером, сначала свежие. Искать их по дереву диска больше не нужно.
- Закреплённые папки. Нужные папки закрепляются и всегда под рукой в строке над библиотекой; «Добавить папку» открывает обычное окно выбора папки Windows.
- Папки внутри библиотеки тоже стали карточками с обложкой и числом видео вместо серых прямоугольников. Правый щелчок по папке: закрепить, открыть в Проводнике, скрыть из списка.
- Исправлено: кнопки «Жалоба» и «Пожелание» снова отправляют сообщения (сервер автора переехал на новый адрес).

Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с любой программой без платной цифровой подписи.
