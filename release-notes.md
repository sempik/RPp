**Скачать:** `RPp-Setup.exe` — установщик, `RPp-portable.zip` — версия без установки.

Что нового в 1.3.1:
- Релиз собирается серверами GitHub из открытого кода, к файлам прикреплено подтверждение происхождения и контрольные суммы SHA-256.
- Перед установкой показывается, что именно сделает установщик и чего программа не делает.
- В «Приложениях» Windows у RPp появились ссылки на исходный код и страницу версий.

Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с любой программой без платной цифровой подписи.
