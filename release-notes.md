**Скачать:** `RPp-Setup.exe` — установщик, `RPp-portable.zip` — версия без установки.

Что нового в 1.5.0:
- Вкладка «Все видео»: все видеофайлы с локальных дисков плитками, по дням, с подписью папки.
- Поиск идёт в фоне при запуске и не мешает работе. Системные папки, папки игр и файлы меньше 1 МБ пропускаются. Прошлый результат сохраняется, поэтому вкладка открывается сразу.
- Кнопка «Обновить» (F5) на вкладке запускает поиск заново.

Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с любой программой без платной цифровой подписи.
