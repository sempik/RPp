**Скачать:** `RPp-Setup.exe` — установщик, `RPp-portable.zip` — версия без установки.

Что нового в 1.4.0:
- Обновление прямо в программе. Когда выходит новая версия, RPp показывает уведомление. По кнопке «Обновить» он сам скачивает установщик, сверяет его контрольную сумму, ставит и перезапускается. Можно вместо этого открыть страницу версии на GitHub.
- Проверка обновлений почти не нагружает компьютер: это один короткий запрос к GitHub при запуске и раз в 6 часов. Скачивание начинается только по вашей кнопке.
- Esc во время просмотра возвращает в библиотеку. Если открыто меню, панель обрезки или полноэкранный режим, Esc сначала закрывает их.

Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с любой программой без платной цифровой подписи.
