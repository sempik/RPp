**Скачать:** `RPp-Setup.exe` — установщик, `RPp-portable.zip` — версия без установки.

Что нового в 1.6.1 — исправления ошибок:
- Во весь экран окно «Удалить видео?», справка и уведомления не было видно, а клавиши в них работали: Del и Enter удаляли файл без видимого подтверждения. Теперь всё показывается поверх видео.
- Если закрыть RPp во время сохранения фрагмента, рядом с записью оставался недописанный битый файл. Теперь RPp спрашивает, прервать ли сохранение, и убирает недописанный файл.
- Отмена подготовки FLV/TS или выход в библиотеку в этот момент иногда всё равно запускали видео в фоне со звуком.
- Окно открывалось за пределами экрана, если в прошлый раз было на отключённом мониторе.
- Если запомненная папка пропала (удалена, флешка вынута), библиотека была пустой. Теперь открывается ближайшая существующая папка или «Видео».
- После каждого обновления в папке временных файлов оставался установщик на 130 МБ. Теперь он удаляется.
- Файлы TypeScript (.ts) больше не показываются как видео.
- Пока ничего не происходит (библиотека, пауза), RPp больше не нагружает процессор. Библиотека с тысячами видео занимает меньше памяти.
- «Текст с кадра» больше не показывает рамки поверх другого кадра, если во время распознавания нажать воспроизведение или перемотать.
- Если запись повреждена в середине, RPp предлагает пропустить испорченное место, а не перекодировать весь файл.
- Длинные уведомления больше не обрезаются краем окна. Шаг по кадрам не сбивается после перемотки. Позиции просмотра запоминаются для 300 последних видео, а не для 300 первых.
- При удалении RPp удаляются и её временные копии видео (до 20 ГБ) и превью.

Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с любой программой без платной цифровой подписи.
