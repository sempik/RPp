**Скачать:** `RPp-Setup.exe` — установщик, `RPp-portable.zip` — версия без установки.

Что нового в 1.6.0:
- Текст с кадра: кнопка «Aa» в плеере или клавиша C. Надписи на кадре (ники, чат, номера) подсвечиваются рамками, клик по рамке копирует текст. Есть и «Копировать всё». Если кадр увеличен, читается только видимая часть, так мелкий текст распознаётся точнее. Работает на встроенном распознавании Windows, без интернета, и тратит ресурсы только в момент нажатия.
- Удаление видео прямо из RPp: правый клик по плитке → «Удалить», в плеере меню «⋯» → «Удалить видео» или клавиша Del. Файл уходит в Корзину Windows, оттуда его можно восстановить.
- Превью в библиотеке: задержите курсор на плитке на 2 секунды, и видео начнёт тихо играть прямо в ней. С того места, где вы остановились, или чуть дальше начала записи.
- Кнопки «Жалоба» и «Пожелание» в библиотеке и в меню «⋯». Сообщение уходит автору RPp. Можно оставить контакт для ответа.
- Открываются записи OBS в форматах FLV и MPEG-TS (.ts). Раньше на них была ошибка «кодек не поддерживается». Теперь RPp за несколько секунд перепаковывает такой файл в MP4 без потери качества и сразу показывает.
- Если видеокарта не умеет показывать кодек записи, RPp предлагает перекодировать копию для просмотра. Исходный файл не меняется, обрезка делается из оригинала.
- Запись, которую OBS ещё пишет, больше не выдаёт ошибку. RPp показывает «Запись ещё идёт» и сам откроет видео, как только запись остановится.
- Если файл всё-таки не открывается, видно настоящую причину: запись оборвалась, файл пропал и т. д.
- Рамка «Отпустите, чтобы открыть» больше не выскакивает сама при перемотке. Она появляется, только когда видео перетаскивают из Проводника.

Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с любой программой без платной цифровой подписи.
