**Скачать:** `RPp-Setup.exe` — установщик, `RPp-portable.zip` — версия без установки.

Что нового в 1.9.0:
- Превью при наведении стало живым. Плитка под курсором чуть увеличивается, и запись почти сразу начинает играть прямо в ней, без звука. Раньше нужно было держать курсор две секунды.
- RPp открывает фото: PNG, JPG, WebP, GIF, BMP и AVIF. Через «Открыть файл», перетаскиванием в окно или правой кнопкой → «Открыть с помощью» → RPp. Программой по умолчанию для картинок RPp себя не назначает.
- На фото работает всё, что удобно на видео: приближение колесом до 16×, миникарта, «Текст с кадра». Стрелки ← → листают фото из той же папки, Ctrl+C копирует картинку в буфер.
- Фото видны в папках библиотеки рядом с видео, так что скриншоты кадров из «Изображения\RPp» можно смотреть тут же. Вкладка «Все видео» по-прежнему показывает только видео.
- Превью в библиотеке появляются быстрее в больших папках: сначала готовятся те плитки, которые сейчас на экране.

Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с любой программой без платной цифровой подписи.
