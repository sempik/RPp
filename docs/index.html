Безопасность

Это безопасно?

Windows предупреждает о RPp только потому, что у программы нет платной цифровой подписи. Вот что можно проверить самому.

Весь код открыт. Около 1400 строк в репозитории, без сторонних библиотек и скрытых загрузок.
Собрано серверами GitHub. Каждый релиз собирается из кода репозитория, к файлам прикреплено подтверждение происхождения.
Проверено антивирусами. Каждый релиз проверяет VirusTotal, около 70 антивирусов. Отчёты в описании релиза.
Контрольные суммы. В релизе есть SHA256SUMS.txt, сравните с Get-FileHash RPp-Setup.exe.
Без прав администратора. Ставится в папку пользователя и не трогает системные файлы.
Сама ничего не отправляет. В интернет обращается к GitHub, чтобы узнать о новой версии. Сообщение автору уходит, только если вы сами отправите его кнопкой «Жалоба» или «Пожелание».
Не работает в фоне. Не запускается вместе с Windows: закрыли окно, программа завершилась.
Записи без вас не трогает. Фрагменты сохраняются отдельными файлами, удалённая вами запись уходит в корзину. Сама RPp удаляется через «Параметры».

Установка

Три шага, и можно смотреть

  1. Скачайте и запустите установщик. Права администратора не нужны, ярлыки появятся в «Пуске» и на рабочем столе.
  2. Подтвердите запуск. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
  3. Откройте запись. RPp покажет папку «Видео», а любой файл можно открыть через «Открыть с помощью».
